DogDex 1.8.15 — clean prices and printing order

Re-export the mobile viewer and commit/push docs to update GitHub Pages.

Validation uses the existing price, catalogue chronology, card UI, real HTTP product-reuse workflow and public-export tests, plus the reported Base Set order case.
