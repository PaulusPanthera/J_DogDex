# DogDex 1.8.19 — EN/DE printing references

This bounded review adds 21 explicit physical printings to existing card identities:

- EN and DE Prismatic Evolutions Riolu 050, Houndour 062, Houndoom 063 and
  Furfrou 088: one Poké Ball and one Master Ball reverse each (16 total).
- EN Paldean Fates Greavard 042 and Maschiff 062: Costco Cosmos parallel foil.
- EN Houndoom OBF 133 and Greavard PAF 042: Trick or Trade 2024 stamp, non-holo.
- EN Delphox Chaos Rising 013: expansion-logo launch holo. Its unspecified foil
  pattern is retained; the evidence does not establish Cosmos.

Retail products stay distribution relationships under Products. Original set
numbers and all 4,594 pre-existing printing IDs/physical keys are retained. No
German product variant is inferred from an English product or a provider mirror.

The finder now checks foil pattern, stamp, size, material and English Base Set
Shadowless before suggesting provider references. Exact candidate references
were refreshed for 562 printing targets in the reviewed EN/DE card families.
They remain unconfirmed: guide prices still require a collector-confirmed match.
New references carry a physical-key fingerprint and stop suggesting a stale
product after the printing is edited. Existing confirmed matches stay intact.

The generic accepted total changes from 4,584 to 4,605; raw research records from
4,594 to 4,615. A local manual printing can increase the personal denominator.
This is a targeted reference review, not a complete factual audit of all sets.
Images, rarity classifications, regional dates and existing physical tuples are
unchanged. Private date uncertainty is recorded in the separate collection report.

Install this patch on application 1.8.18. Close DogDex, extract the update ZIP
into the existing DogDex folder, and run UPDATE_DOGDEX.bat. Installation backs
up managed changes and a coherent collection database, checks owned IDs on a
copy, and rolls back if validation fails. The full Windows ZIP is the alternative
for a fresh installation; it is not a second required patch.

After installation, run CHECK_DOGDEX.bat. Export the mobile viewer again when
ready. Nothing is committed, pushed or published automatically.

Public reproducible facts, source receipts, original tuple keys and reviewed
references are in data/research/reference_1819/. The personal audit report is
separate and is never bundled into a public export or release.
